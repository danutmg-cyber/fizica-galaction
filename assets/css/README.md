# Stilurile platformei

## Fișiere

- `layout.css` – structură generală și containere;
- `lesson-app.css` – lecții interactive pe pagini;
- `lessons.css` – elemente specifice lecțiilor;
- `tests.css` – teste și verificări;
- `mobile.css` – ajustări pentru ecrane mici;
- `main.css` – stiluri generale;
- `style.css` – stiluri vechi, aflate în curs de migrare.

## Reguli

- folosește variabile CSS pentru culori;
- păstrează contrast bun în ambele teme;
- nu reduce textul sub `16px` pe telefon;
- butoanele trebuie să aibă minimum `44px` înălțime;
- evită stilurile inline;
- noile lecții trebuie să folosească `lesson-app.css`.
