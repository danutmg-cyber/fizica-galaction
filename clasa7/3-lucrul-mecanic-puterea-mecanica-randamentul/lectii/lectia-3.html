Randamentul

O forță mai mică nu înseamnă automat un consum mai mic. Urmărește lucrul util și pierderile.

← Toate lecțiileExperimenteazăExplicații și exempleFișa de lucru

Ideea de pornire

Randamentul compară lucrul mecanic util cu lucrul mecanic consumat pentru același proces. La urcarea uniformă pe plan, lucrul util este creșterea energiei potențiale mgh, iar cel consumat este lucrul tracțiunii Fl. Diferența este transferată în alte forme de energie, de exemplu energie internă prin frecare; energia nu dispare. Lucrul total al tuturor forțelor pe corp este zero la mișcare uniformă, dar acesta nu este lucrul util.

η = Lutil / Lconsumat
η% = 100 · Lutil / Lconsumat
Lutil = mgh; Lconsumat = F · l
Cu pierderi: 0 < η < 1; în modelul ideal fără pierderi: η = 1

Schimbă datele și urmărește efectul

Model de urcare uniformă, cu tracțiune paralelă cu planul și frecare de alunecare. Înălțimea rămâne mai mică decât lungimea planului. Contururile barelor corespund consumului pentru cursa completă.

  1. Mărește frecarea: lucrul util pentru aceeași masă și înălțime nu se schimbă, dar consumul crește și randamentul scade.
  2. Prelungește planul păstrând înălțimea: se modifică forța necesară și drumul pe care acționează frecarea. Compară lucrurile, nu doar forțele.
  3. Alege frecare zero: L_consumat = L_util și η = 100%. Schimbă apoi masa: în acest model, lucrurile și forțele se schimbă, dar randamentul rămâne același.

Lecția 3 – Randamentul

În această lecție înveți să compari efectul util obținut cu efortul consumat pentru funcționarea unui dispozitiv.

Ideea-cheie: niciun dispozitiv real nu transformă tot efortul consumat în rezultat util.
De ce folosim planul înclinat?
Observ

De ce folosim planul înclinat?

Planul înclinat este folosit pentru a urca mai ușor corpuri grele: în camion, pe rampe, în mine sau la intrarea în clădiri.

Pe plan înclinat, forța necesară poate fi mai mică decât greutatea corpului, dar deplasarea este mai lungă.

Un dispozitiv este avantajos dacă ajută la realizarea acțiunii utile, dar el consumă totuși lucru mecanic.
Ce este randamentul?
Rețin

Ce este randamentul?

Randamentul unui dispozitiv arată cât din lucrul mecanic consumat se transformă în lucru mecanic util.

\[ \eta=\frac{L_{util}}{L_{consumat}} \]

Aceeași idee se poate exprima și cu puterile:

\[ \eta=\frac{P_{utilă}}{P_{consumată}} \]
Randamentul nu are unitate de măsură. Este o mărime adimensională.
Ce înseamnă valoarea randamentului?
Interpretare

Ce înseamnă valoarea randamentului?

Pentru un dispozitiv real, randamentul este pozitiv și mai mic decât 1:

\[ 0 < \eta < 1 \]

Deseori îl scriem în procente:

\[ \eta\%=\eta \cdot 100\% \]
Valoare Interpretare
\(\eta=0{,}75\) 75% din efortul consumat devine efect util.
\(\eta=0{,}90\) Dispozitivul are pierderi mai mici decât la 75%.
Randamentul la urcarea unui corp
Plan înclinat

Randamentul la urcarea unui corp

Pentru ridicarea uniformă a unui corp pe verticală, lucrul mecanic util este:

\[ L_{util}=G\cdot h \]

Pe planul înclinat, lucrul mecanic consumat este:

\[ L_{consumat}=F\cdot l \]

De aceea:

\[ \eta=\frac{G\cdot h}{F\cdot l} \]
\(G\) este greutatea corpului, \(h\) este înălțimea, \(F\) este forța de tracțiune, iar \(l\) este lungimea planului înclinat.
Calculăm randamentul
Exemplu numeric

Calculăm randamentul

Pentru un dispozitiv, lucrul mecanic util este \(L_{util}=800\,J\), iar lucrul mecanic consumat este \(L_{consumat}=1000\,J\).

\[ \eta=\frac{L_{util}}{L_{consumat}} \] \[ \eta=\frac{800\,J}{1000\,J}=0{,}8 \] \[ \eta\%=0{,}8\cdot 100\%=80\% \]
Răspuns: randamentul dispozitivului este \(0{,}8\), adică \(80\%\).
Aplicăm formula
Exemplu pe plan înclinat

Aplicăm formula

Un corp cu greutatea \(G=200\,N\) este ridicat la înălțimea \(h=1\,m\). Pe planul înclinat se aplică forța \(F=80\,N\), pe distanța \(l=3\,m\).

\[ L_{util}=G\cdot h=200\,N\cdot 1\,m=200\,J \] \[ L_{consumat}=F\cdot l=80\,N\cdot 3\,m=240\,J \] \[ \eta=\frac{200\,J}{240\,J}\approx 0{,}83 \approx 83\% \]
Randamentul nu este 100%, deoarece apar pierderi, de exemplu prin frecare.
Sinteză
Reține

Sinteză

  • Randamentul se notează cu \(\eta\).
  • Formula de bază este \(\eta=\frac{L_{util}}{L_{consumat}}\).
  • Se poate calcula și cu puterile: \(\eta=\frac{P_{utilă}}{P_{consumată}}\).
  • Randamentul nu are unitate de măsură.
  • În practică, randamentul este mai mic decât 1.
Când transformi în procente, înmulțești valoarea lui \(\eta\) cu \(100\%\).
