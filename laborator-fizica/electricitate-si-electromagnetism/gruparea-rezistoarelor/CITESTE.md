# Laborator: Gruparea rezistoarelor

Copiază directorul:

laborator-fizica/electricitate-si-electromagnetism/gruparea-rezistoarelor/

în repository.

Fișiere:
- index.html
- data.json

Pagina are 7 pagini interne.
Headerul apare numai în pagina 1.
Footerul apare numai în pagina 7.

Relații utilizate:
- serie: Rech = R1 + R2 + ... + Rn
- paralel: 1/Rech = 1/R1 + 1/R2 + ... + 1/Rn
- două rezistoare în paralel: Rech = R1R2 / (R1 + R2)
- verificare experimentală: Rech = U / I
