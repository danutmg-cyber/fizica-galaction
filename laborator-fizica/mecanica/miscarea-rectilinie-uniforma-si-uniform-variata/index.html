Cum descriem mișcarea unui corp pe o linie dreaptă?

Vom analiza poziția, viteza și accelerația unui corp care se deplasează rectiliniu. Vom compara mișcarea uniformă cu mișcarea uniform variată .

Ce vei observa

  • cum se schimbă poziția în timp;
  • când viteza este constantă;
  • când viteza se modifică uniform;
  • cum se interpretează accelerația.

Ce vei realiza

  • tabel de valori;
  • graficul poziției \(x(t)\);
  • graficul vitezei \(v(t)\);
  • comparație între MRU și MRUV.
Mișcarea este descrisă față de un reper. În acest laborator folosim o axă rectilinie \(Ox\).
Pagina 2 • MRU

Mișcarea rectilinie uniformă

În MRU, corpul se deplasează pe o linie dreaptă cu viteză constantă.

Ecuația poziției

\[ x=x_0+vt \]

\(x_0\) este poziția inițială, \(v\) este viteza, iar \(t\) este timpul.

Viteza și accelerația

\[ v=\mathrm{constant} \]
\[ a=0 \]
Grafic Formă Interpretare
\(x(t)\) dreaptă oblică panta dreptei reprezintă viteza;
\(v(t)\) dreaptă orizontală viteza este constantă.
Pagina 3 • MRUV

Mișcarea rectilinie uniform variată

În MRUV, accelerația este constantă, iar viteza se schimbă uniform în timp.

Legea vitezei

\[ v=v_0+at \]

Dacă \(a>0\), viteza crește. Dacă \(a<0\), viteza scade.

Ecuația poziției

\[ x=x_0+v_0t+\frac{at^2}{2} \]

Termenul \(\frac{at^2}{2}\) produce forma parabolică a graficului \(x(t)\).

Grafic Formă Interpretare
\(x(t)\) curbă parabolică poziția nu mai variază liniar;
\(v(t)\) dreaptă oblică panta dreptei reprezintă accelerația.
Accelerația medie se poate calcula prin:
\[ a=\frac{\Delta v}{\Delta t} \]

Pagina 6 • Aplică

Exemplu numeric pentru MRUV

Un corp pornește de la \(x_0=2\,\mathrm{m}\), cu viteza inițială \(v_0=3\,\mathrm{m/s}\) și accelerația \(a=2\,\mathrm{m/s^2}\). Determinăm poziția și viteza la \(t=4\,\mathrm{s}\).

\[ v = v_0+at = 3+2\cdot4 = 11\,\mathrm{m/s} \]
\[ x = x_0+v_0t+\frac{at^2}{2} = 2+3\cdot4+\frac{2\cdot4^2}{2} = 30\,\mathrm{m} \]

Pagina 7 • Concluzie

Ce ai descoperit?

MRU

\[ x=x_0+vt \]

Viteza este constantă, iar accelerația este zero.

MRUV

\[ v=v_0+at \]
\[ x=x_0+v_0t+\frac{at^2}{2} \]

Graficul \(x(t)\)

Este o dreaptă în MRU și o parabolă în MRUV.

Graficul \(v(t)\)

Este orizontal în MRU și o dreaptă oblică în MRUV.

Ideea finală: viteza descrie cât de repede se schimbă poziția, iar accelerația descrie cât de repede se schimbă viteza.
La interpretarea graficelor verifică întotdeauna mărimile de pe axe, unitățile de măsură și sensul mișcării.
